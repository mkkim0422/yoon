개요

이 시스템이 하는 일

Google Cloud 에서 받은 청구 CSV 와 사내 Price List 엑셀을 입력받아, 고객사별로 GMP 인보이스를 자동 생성합니다. 단일 회사 정산과 전체 일괄 정산 두 모드를 지원합니다.

① 입력

월별 청구 CSV (회사 전체 한 파일) + 단가 기준이 되는 Price List xlsx

② 처리

회사별 SKU 추출 → Waterfall(무료 한도 → tier 단가) 적용 → KRW 환산

③ 출력

회사별 Invoice.xlsx (+ 옵션 PDF). 일괄 모드는 회사별 폴더로 ZIP 묶음

단일 진실 소스 원칙: "어떤 SKU 가 쓰였는가" 는 CSV, "각 SKU 의 단가/무료한도" 는 Price List 만 본다. 중간 정의 파일(master_data.csv 등) 은 정산 경로에서 더 이상 참조하지 않는다.

1단계 — 파일 업로드

CSV + Price List 올리기

  • 1
    월별 청구 CSV 업로드 Google Cloud Console 에서 다운받은 그달의 청구 CSV (모든 회사 합본). 사이드바 상단 "📁 CSV 업로드" 영역에 드래그.
  • 2
    Price List xlsx 업로드 (USD / KRW) SKU 별 단가·무료한도 기준표. USD 단가표·KRW 단가표를 통화별로 따로 보관. 시스템이 청구 CSV 의 환산 통화를 자동 감지해 둘 중 알맞은 걸 사용.
  • 3
    자동 감지 확인 정산월(예: 2026-04)·통화(USD/KRW) 가 사이드바에 자동 표시됨. 다르면 수동 조정 가능.
주의: CSV 가 잘못된 월 데이터를 포함하면 "정산월" 을 수동으로 맞춰 주세요. 자동 감지는 인보이스 날짜 행을 읽는 방식입니다.
단일 정산 모드

회사 1개 정산하기 — 회사 선택

상단 토글을 OFF 로 바꾸면 단일 정산 모드. 결제 계정 (회사) 을 하나 골라 그 회사만 정산합니다.

  • 1
    🔍 결제 계정 검색 회사명 일부 입력 → 부분 문자열 매칭. 예: "splyt" 입력 시 "splyt" 가 이름에 포함된 회사만 표시. (부분수열 매칭 X)
  • 2
    드롭다운에서 선택 검색 결과 좁혀진 후 드롭다운에서 정산할 회사 선택. 이전 선택은 자동 복원.
💡 검색 팁: 회사 정식 명칭 일부만 입력하면 됩니다. 대소문자 무관, 한글 정규화도 적용됨.
단일 정산 모드

옵션 설정 → 정산 실행

환율 / 기준일 / 은행

USD 회사면 환율 입력. 환율 적용 기준일(보통 전월 말일 영업일) 과 송금 은행명도 함께 표기.

과금 방식

"회사 통합" (기본) vs "프로젝트별" 선택. 후자는 프로젝트마다 별도 시트.

SKU 노출 순서

드래그로 인보이스 표시 순서 조정. 미노출 SKU 지정 가능.

직접 등록 SKU

사용량 0 이라도 빈 라인으로 인보이스에 노출하고 싶은 SKU 추가.

설정이 끝나면 우측의 "▶ 정산 실행" 버튼 클릭. 1~3초 후 결과 영역에 인보이스가 표시되며 엑셀이 자동 다운로드.

일괄 정산 모드 · 환율 일괄 입력

환율 한 번에 입력하기

USD 단가표를 쓰는 회사들에 환율을 동시 적용. 회사별로 따로 조정도 가능.

  • 1
    일괄 환율 입력 "💱 일괄 입력 (USD 회사에만 적용)" 영역에 환율(₩/$) + 환율 날짜 입력. → 체크된 USD 회사 전체 자동 동기화.
  • 2
    회사별 개별 조정 (선택) 회사 행에서 환율값/기준일/은행/문구를 회사별로 다르게 설정 가능. 회사별로 마지막 저장값이 다음 정산에 자동 반영.
  • 3
    KRW 단가표 회사 환율 불필요 → 입력 무시.
일괄 정산 모드 · 비용발생 SKU 정책

"미노출 지정한 SKU 에 비용이 있을 때" 처리

사용자가 미노출(hidden) 처리한 SKU 중 무료 한도를 초과한 항목(=실제 청구액 발생) 이 있으면, 엑셀 총액이 실제 청구액보다 적게 나옴. 이 경우 어떻게 처리할지 선택:

그대로 (as_is)

경고만 띄우고 미노출 그대로 정산. 사용자가 결과 검토 후 직접 판단.

건너뛰기 (skip)

비용발생 SKU 있는 회사는 정산 스킵. 정산 결과에 포함 안 됨.

노출로 이동 (move)

해당 SKU 를 hidden 에서 빼고 인보이스 끝에 추가 후 재정산. 영구 저장됨.

권장: 평소엔 그대로 두고 회사별 정산 로그에서 ⚠ 표시를 보고 개별 대응.

자동 안전장치

엑셀 자체 정합성 검사

외부 발송 전 사고를 막기 위해, 정산 후 생성된 엑셀을 자동으로 다시 검사합니다.

🔍 위험 수식 패턴

*0 *0.0 같은 곱하기-0 수식 (청구액 0 사고)

🔍 빈 수식 / 참조 오류

SUM() #REF! #NAME? 탐지

🔍 SKU 누락

Python 이 계산한 SKU 가 엑셀 시트에 빠져 있는지 대조

🚨 발견 시

결과 영역 상단에 빨간 박스 + 상세 expander 자동 펼침. 발송 전 반드시 확인.

경고 발생 회사는 ZIP 다운로드는 되지만 외부 발송 전 반드시 해당 엑셀을 열어 확인하세요.
결과 다운로드

정산 끝나면

  • ✓
    오버레이 사라지고 결과 영역 노출 "결과 요약 (N/N 성공)" 헤더 + 정합성 경고(있다면) + 회사별 로그 expander.
  • 📦
    ZIP 다운로드 (일괄) "📦 zip 다운로드 (전체정산_YYYYMM_타임스탬프.zip)" 버튼 클릭. 회사별 폴더 안에 sGMP_Invoice_회사명.xlsx (+ .pdf) 들어 있음.
  • 📄
    개별 다운로드 (단일) 단일 정산은 정산 직후 엑셀이 자동 다운로드. PDF 옵션 켜면 PDF 도 함께. 재다운로드 버튼도 제공.
  • ⏱
    단계별 소요시간 (디버그) 결과 영역 하단 expander 에 회사별 전처리/계산/엑셀 생성 시간 보관. 평소엔 닫혀 있고 필요할 때 펼쳐 봄.
FAQ · 문제 해결

자주 묻는 질문

  • Q
    일괄 정산이 너무 오래 걸려요 회사 60개면 보통 1.5~2분 소요. 진행 카드의 "남은 약 N분" 으로 확인. 멈춰 보이면 회전 스피너 확인.
  • Q
    🚨 정합성 경고가 떴어요 결과 상단의 "정합성 경고 상세" expander 열어 어떤 셀에 어떤 패턴이 박혔는지 확인 → 해당 회사 엑셀 열어 직접 확인 → 필요 시 SKU 노출/미노출 재조정 후 재정산.
  • Q
    회사가 검색되지 않아요 회사명 일부를 정확히 입력. 부분수열(글자 떨어진 매칭) 안 됨 — 연속된 글자가 회사명 안에 그대로 있어야 함.
  • Q
    회사 옵션을 바꿨는데 다음 정산에 안 반영돼요 "정산하기" 버튼을 한 번 더 눌러야 새 옵션으로 재계산됨. 옵션 변경만으로 자동 재계산 X.
  • Q
    오버레이가 안 사라져요 드물게 세션 단절 시 발생. F5 또는 페이지 새로고침으로 해결. 정산 결과는 백엔드에 안 남으므로 다시 정산 필요.
